# Contributing

Contributions are welcome when they preserve the offline-only scope and fail-closed validation model.

1. Fork the repository.
2. Create a focused branch.
3. Build the Win32/x86 Release target.
4. Test only with a lawful offline copy.
5. Do not upload game files, proprietary assets, personal paths, logs, tokens, or signing keys.
6. Open a pull request explaining the change and the tested executable build.

Contributions for online play, anti-cheat bypass, stealth, authentication bypass, DRM circumvention, or third-party systems will not be accepted.
